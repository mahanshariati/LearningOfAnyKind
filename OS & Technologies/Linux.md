### 103.1 Work on the command line
#### Exploring Your Linux Shell Options
- **Bash** : the most popular and commonly used. It is also available for Windows 10, macOS, and Solaris operating systems.
- **Dash** : This shell does not allow command-line editing or command history, but it does provide faster shell program (also called a script) execution.
- **KornShell** : compatible with the Bourne shell and supports advanced programming features, such as those available in the C programming languages.
- **tcsh** : incorporates elements from the C programming language into shell scripts.
- **Z shell** : incorporates features from Bash, tcsh, and KornShell.
